**ghee** (formerly git-goblin) is a shell shortcut manager: 616+ aliases and functions across 32 modules, plus a Python/Rich fuzzy TUI. Source it into bash or zsh and the everyday CLI gets shorter.

The project is on [GitHub](https://github.com/juleshenry/ghee). MIT licensed. Also installable as [`ghee-cli`](https://pypi.org/project/ghee-cli/) on PyPI.

Coverage includes Git, Docker, Kubernetes, AWS, GCP, Terraform, Heroku/Vercel/Fly/Railway, GitHub CLI, npm/yarn/pnpm, Python/pip/uv/poetry, Rust, Go, Redis, Postgres, MongoDB, Nginx, systemd, tmux, networking, recon, AI/LLM helpers, media tools, and more.

## The Greatest Hits

```bash
gg "fix the auth bug"     # git add -A && git commit -m "..." && git push
gs                        # git status
gd                        # git diff
gb                        # git branch
gco feature               # git checkout feature
gpr                       # create GitHub PR via gh
gsquash 3                 # squash last 3 commits
gwip                      # commit everything as WIP
gunwip                    # undo the last WIP commit
presto                    # nuclear option: wipe git history (with confirmation)
```

Docker:

```bash
dps                       # docker ps
dcu                       # docker compose up -d
dcd                       # docker compose down
dex container bash        # docker exec -it container bash
```

Kubernetes:

```bash
kgp                       # kubectl get pods
kl pod-name               # kubectl logs
kex pod-name bash         # kubectl exec -it
```

Package managers — note **`pni`**, not `pi`, for pnpm (the short name `pi` collides with a popular harness now):

```bash
ni                        # npm install
yi                        # yarn install
pni                       # pnpm install
```

You do not memorize all 616. You memorize the ones you use. For the rest, there is `G`.

## The `G` Command

### Best-guess

```bash
G 'docker logs'
```

Fuzzy-match a raw command or a vague description to the closest shortcut, show the docs, copy the alias to the clipboard.

### Add / remove customs

```bash
G -a olist 'ollama list'
G -rm olist
G ls
```

Customs live in `~/.ghee-custom`, survive updates, and are searchable like builtins. Clash detection warns before you overwrite a system command or an existing ghee alias.

### Interactive Rich TUI

```bash
G
```

Full-screen fuzzy finder with live preview (Rich). Arrows navigate, Enter selects, Tab copies, Esc quits. Needs Python 3.8+ and the `rich` package (the installer creates a `ghee-venv` for you).

Other useful entry points: `G update`, `G info docker`, `G -q 'find large files'` (optional Ollama), `G --sync <gist_url>`.

## Setup

```bash
git clone https://github.com/juleshenry/ghee.git
cd ghee
./setup-ghee
source ~/.zshrc   # or ~/.bashrc
```

Detects bash/zsh, backs up your RC, wires `bin/` + `tools/` onto `$PATH`, sources `modules/*.sh`. Uninstall with `./setup-ghee --remove`.

## Extra Tools

Still in the box:

**`kash`** — file-backed function cache (`functools.lru_cache`, but on disk across process restarts).

**`autosave-git-recursively.py`** — walk a tree and auto-commit/push every git repo (cron-friendly).

**`repoinspector.py`** — aggregate open issues across a GitHub user's public repos.

## Why Not Just Oh My Zsh?

1. **Scope.** OMZ git aliases are git-only. ghee spans the whole modern toolchain.
2. **`G`.** Searchable registry + TUI + custom shortcuts, not a file you grep.
3. **Shape.** Modular `modules/*.sh` registry, Python TUI when you want it, plain aliases when you do not. Works on bash and zsh.

616+ shortcuts. One spoon of ghee.
